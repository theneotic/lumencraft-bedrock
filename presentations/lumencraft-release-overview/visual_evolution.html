FEATURE EVOLUTION

The Visual Stack Expanded Layer by Layer

Core PBR remained the foundation. Each release family added a new visual system around it.

Later releases concentrated on believable water, readable sky, and a distinct underwater identity instead of merely increasing texture resolution.
