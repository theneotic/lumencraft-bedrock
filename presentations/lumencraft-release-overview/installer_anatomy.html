INSTALLATION GUIDE

Choose the Installer by Goal

The extension tells Minecraft whether it is importing one pack or a resource-and-behavior bundle.

Installer
What it contains
Where it is activated
Best use
RESOURCE .MCPACK
Direct visual pack
One resource pack with a root-level manifest.json.
World Settings → Resource Packs.
Safest first Android test when validating visuals and import behavior.
COMPANION .MCPACK
Behavior / script pack
One Script API behavior pack for automated particles and audio playback.
World Settings → Behavior Packs.
Use only alongside its matching resource build and version.
COMPLETE .MCADDON
Combined installer
Two inner packs: one resource `.mcpack` plus one companion `.mcpack`.
Open directly with Minecraft; activate the imported resource and behavior packs in the world.
Best all-in-one experience. Never rename an `.mcaddon` to `.mcpack`.
