# LumenCraft Luminous Dreams — Night, Water and Firefly Companion

Optional behavior pack for the matching resource pack. It preserves the weather and audio systems and adds sparse falling leaves, wind-blown dust, nighttime fireflies in forest and swamp biomes, and the High Graphics aurora.

The matching resource pack supplies moonlight keyframes, profile-specific animated caustic sheets, underwater volumetric fog/light-ray settings, and the firefly particle sprite.

Test with `/time set night`, visit a supported forest or swamp, and enter a clear body of water with Vibrant Visuals enabled.
